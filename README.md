Здесь собраны мои учебные проекты: обработка событий, загрузка данных в хранилище, преобразования в dbt и работа с данными на Python.

| Проект | Что внутри | Технологии |

## Темы проектов

- **Загрузка и обработка данных:** события Kafka, Spark Structured Streaming и DAG в Airflow.
- **Хранилища и преобразования:** PostgreSQL, Vertica, SQL и dbt.
- **Разработка на Python:** коллекции, файловые индексы, модели данных и тестирование.

В README проектов описаны их назначение, структура и условия запуска. Репозитории с книгами и сторонними инструментами сохранены как учебные материалы и форки.
